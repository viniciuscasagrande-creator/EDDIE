# Prompt mestre — EDDIE 9.7 a 9.13

Trabalhe sobre o projeto atual sem reconstruí-lo. Leia primeiro `EDDIE_9_7_A_9_13_LEIA_PRIMEIRO.md` e todos os arquivos `docs/EDDIE_9_*.md`.

Implemente na ordem 9.7 → 9.13. Não copie CSS do SafeSaff. SafeSaff e vídeos são referência funcional; EDDIE é a referência visual e arquitetural.

Antes de criar model, tabela, controller, service, componente ou rota, procure equivalente existente. Reutilize e complete. Não crie duplicação de Ledger, saldo, evento, produtor, pedido ou cliente.

Prioridade máxima: remover mocks e fechar UI → API → banco. Não marque tarefa como concluída se só a interface existir.

Ao final de cada macrofase:
- listar arquivos alterados;
- listar endpoints utilizados/criados;
- listar migrations;
- executar build/testes possíveis;
- registrar pendências reais, sem mascará-las com dados fake.

Não remover funções úteis apenas porque estão incompletas: complete-as. Não adicionar funcionalidades sem utilidade operacional demonstrável.
