# EDDIE 11.16.11 — Recuperação Integral do Marketing a partir do vídeo

Este pacote corrige o 11.16: o objetivo NÃO é simplificar o Marketing.
O vídeo `mkt.mp4` é a baseline funcional/visual. Migrar as funções observadas para o EDDIE,
adaptando apenas ao AppShell/design system atual.

## Regra de aceite
Cada item do menu deve abrir uma página funcional. Não vale criar somente item de menu,
placeholder, card vazio ou Markdown. Preservar filtros, abas, cards, tabelas, diagnósticos,
ações, gráficos e integrações equivalentes mostradas no vídeo.
