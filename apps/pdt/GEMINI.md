# PDT (Painel do Produtor) — Frontend Interno

## O que é
Interface interna para organizadores de eventos e colaboradores da DiskIngressos.
Desenvolvida em **Next.js 15 (App Router)** com design corporativo e componentes acessíveis.

## Regras invioláveis
1. O PDT consome a API interna (`apps/api`) completa.
2. NUNCA misturar rotas ou estilos com o site público (`apps/storefront`).
3. Valores monetários são formatados sempre em Real (`pt-BR`) a partir dos centavos inteiros retornados pelos contratos.
4. Interface 100% em pt-BR.
