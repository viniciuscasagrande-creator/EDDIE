# EDDIE 10.0 — Expansão Operacional Massiva

## Objetivo
Transformar a profundidade funcional construída no SafeSaff/PDT anterior em operação real no EDDIE, sem copiar CSS, sem recriar arquitetura e sem dados fictícios.

## Regra de aceite
Uma função só está pronta quando fecha: **UI → validação → API → serviço → Prisma/Ledger → banco → resposta → atualização da UI → erro/auditoria**.

## Entregas deste pacote
- Financeiro ampliado com Fluxo de Caixa, Agenda Financeira, Auditoria e Inteligência Financeira baseados nos dados já carregados do backend.
- Plano de execução massiva para Contabilidade, Eventos, Comercial B2B, Marketing & Remarketing, SAC, Suporte e Estorno.
- Auditoria automática para mocks, nomenclatura proibida e estados de loading problemáticos.
- Prompt mestre do Gemini para executar por código, evitando novas microfases.

## Ordem obrigatória
1. Corrigir conexão API/Banco e contexto Produtor × Evento.
2. Financeiro e Contabilidade.
3. Eventos e Comercial B2B.
4. Marketing & Remarketing.
5. SAC, Suporte e Estorno.
6. Homologação visual, funcional e responsiva.

## Não fazer
- Não copiar CSS do SafeSaff.
- Não criar segundo Ledger, saldo, evento, produtor ou pedido.
- Não usar mocks para esconder backend indisponível.
- Não criar botão sem ação.
- Não usar “360” em nomes visíveis.
- Não substituir módulos existentes por versões simplificadas.
