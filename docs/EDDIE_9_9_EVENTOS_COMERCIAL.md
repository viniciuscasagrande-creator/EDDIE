# EDDIE 9.9 — Eventos + Comercial B2B

## Eventos
Completar o ciclo Produtor → Evento → Sessão → Setor → Lote → Venda/Operação. Incluir cadastro/edição, status, local/data, capacidade, sessões, setores, lotes, tipos de ingresso, regras de venda, canais, equipe/permissões e visão operacional. Reutilizar os modelos Prisma existentes; não criar cadastro paralelo.

## Comercial B2B
Cliente do Comercial = PRODUTOR. Comprador final não pertence ao CRM Comercial.

Completar Dashboard Comercial, Leads, Produtores, Oportunidades, Pipeline, Propostas, Condições Comerciais, Atividades/Follow-up, Contratos quando suportados, Metas e Relatórios.

Fluxo esperado: Lead → Produtor → Oportunidade → Proposta/Condição → Ganho → Ativação → Evento. O Comercial pode visualizar indicadores agregados de eventos/vendas do produtor, sem virar CRM de compradores.
